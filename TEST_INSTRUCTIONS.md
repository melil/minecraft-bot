## 🔧 Полный тест (15 минут)

### Тест 1: Все команды чата
```bash
/say Тест 1
/mc Тест 2
/rcon say Тест 3
/rcon time set day
/rcon weather clear
/rcon list
```

### Тест 2: Цикл включения/выключения мониторинга
1. Включите мониторинг
2. Зайдите на сервер (должно прийти уведомление)
3. Выйдите (должно прийти уведомление)
4. Выключите мониторинг
5. Зайдите снова (НЕ должно прийти уведомление)
6. Включите обратно

### Тест 3: Проверка прав доступа
1. Попросите не-админа отправить `/say`
   - Должна быть ошибка "У вас нет прав"
2. Админ отправляет `/say` - должно работать
3. Обычный админ отправляет `/rcon list`
   - Должна быть ошибка "Команда /rcon доступна только супер-администраторам"
4. Супер-админ отправляет `/rcon list` - должно работать

### Тест 4: Сервер выключен
1. Остановите сервер
2. Попробуйте `/say`
   - Должна быть ошибка "Minecraft сервер не запущен"

### Тест 5: Restart цикл
1. Перезапустите сервер
2. Проверьте, что мониторинг автоматически запустился
3. События должны приходить

## 🐛 Что делать если тест не проходит

### RCON недоступен
```bash
# На сервере проверьте:
1. systemctl status minecraft
2. grep rcon /path/to/server.properties
3. mcrcon -H 127.0.0.1 -P 25575 -p ваш_пароль "say Test"
```

### События не приходят
```bash
# Проверьте логи Minecraft:
journalctl -u minecraft.service -n 50 --no-pager

# Должны быть строки типа:
[Server thread/INFO]: Player joined the game
[Server thread/INFO]: <Player> message
```

### Бот не отвечает
```bash
# Проверьте логи бота:
tail -f bot.log
# или просто смотрите вывод в консоли

# Ищите ошибки типа:
ERROR - ...
```
