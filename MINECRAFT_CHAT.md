# 💬 Общение между Telegram и Minecraft

Система двустороннего общения между Telegram ботом и Minecraft сервером через RCON.

## 📋 Возможности

### 1️⃣ Отправка сообщений из Telegram в Minecraft

#### Команды:
- `/say <сообщение>` - Отправить сообщение в игровой чат (для админов)
- `/mc <сообщение>` - То же самое (короткая версия, для админов)
- `/rcon <команда>` - Выполнить любую RCON команду (только для супер-админов)

#### Примеры:
```
/say Привет всем игрокам!
/mc Сервер будет перезагружен через 5 минут
/rcon time set day
/rcon weather clear
```

#### Особенности:
- ✅ Только администраторы могут отправлять сообщения
- ✅ В Minecraft отображается имя отправителя: `[Telegram: username] сообщение`
- ✅ Работает только когда сервер запущен
- ✅ Использует RCON для доставки сообщений

---

### 2️⃣ Мониторинг событий из Minecraft

Система отслеживает события на сервере в реальном времени и отправляет уведомления в Telegram группу.

#### Типы событий:

| Событие | Иконка | Описание |
|---------|--------|----------|
| **Вход игрока** | ➕ | Когда игрок заходит на сервер |
| **Выход игрока** | ➖ | Когда игрок покидает сервер |
| **Сообщение в чате** | 💬 | Сообщения из игрового чата |
| **Смерть** | 💀 | Сообщения о смерти игроков |
| **Достижение** | 🏆 | Когда игрок получает достижение |

#### Примеры уведомлений:
```
➕ Steve присоединился к игре
💬 Steve: Привет всем!
🏆 Alex получил достижение: Stone Age
💀 Steve был убит зомби
➖ Alex покинул игру
```

## ⚙️ Настройка

### Включение/выключение мониторинга событий

1. Отправьте команду `/start` боту
2. Нажмите кнопку "⚙️ Настройки"
3. Нажмите "📜 Мониторинг событий MC: 🔴 ВЫКЛ/🟢 ВКЛ"

**По умолчанию мониторинг ВЫКЛЮЧЕН**

### Настройка через код

В файле `bot.py` найдите раздел `MINECRAFT LOG MONITORING`:

```python
# Включить/выключить мониторинг логов
log_monitoring_enabled = False  # Поменяйте на True для включения

# Настройка отображения событий (можно отключить отдельные типы)
MINECRAFT_EVENTS_CONFIG = {
    'join': True,      # Вход игроков
    'leave': True,     # Выход игроков
    'chat': True,      # Сообщения в чате
    'death': True,     # Смерти
    'achievement': True  # Достижения
}
```

## 🔧 Технические детали

### Архитектура

```
┌─────────────────┐         ┌──────────────────┐
│  Telegram Bot   │ ◄─────► │  RCON (mcrcon)   │
└─────────────────┘         └──────────────────┘
        │                            │
        │                            ▼
        │                   ┌──────────────────┐
        └──────────────────►│ Minecraft Server │
                            └──────────────────┘
                                     │
                                     ▼
                            ┌──────────────────┐
                            │  journalctl logs │
                            └──────────────────┘
```

### Модули

1. **`core/minecraft/rcon.py`** - RCON клиент для отправки команд
   - `execute_rcon_command()` - Выполнение произвольных команд
   - `say()` - Отправка сообщений в чат
   - `tellraw()` - Отправка форматированных сообщений

2. **`core/minecraft/log_monitor.py`** - Мониторинг логов
   - `MinecraftLogParser` - Парсер событий из логов
   - `MinecraftLogMonitor` - Система мониторинга в реальном времени
   - События: `PlayerJoinEvent`, `PlayerLeaveEvent`, `ChatMessageEvent`, `PlayerDeathEvent`, `PlayerAchievementEvent`

3. **`core/bot/commands/chat.py`** - Команды бота
   - `/say` - Отправка сообщений
   - `/mc` - Короткий алиас
   - `/rcon` - Выполнение RCON команд

### Как это работает?

#### Telegram → Minecraft (RCON)
1. Пользователь отправляет `/say Привет`
2. Бот проверяет права админа
3. Бот подключается к серверу через SSH
4. Выполняет команду `mcrcon -H 127.0.0.1 -P 25575 -p <пароль> 'say [Telegram: user] Привет'`
5. Сообщение появляется в игре

#### Minecraft → Telegram (Log Monitoring)
1. Фоновая задача каждые 2 секунды читает логи через `journalctl`
2. `MinecraftLogParser` парсит новые строки логов
3. Если найдено событие (вход, выход, чат и т.д.) - создается объект события
4. Событие форматируется и отправляется в Telegram группу

## 🚀 Примеры использования

## 🔒 Безопасность

- ✅ Только администраторы могут отправлять сообщения (`/say`, `/mc`)
- ✅ Только супер-админы могут выполнять RCON команды (`/rcon`)
- ✅ RCON пароль хранится в `.env` файле
- ✅ Команды выполняются через SSH туннель
- ✅ Специальные символы экранируются
- ⚠️ Будьте осторожны с командой `/rcon` - она может выполнять любые серверные команды

## 🐛 Troubleshooting

### Сообщения не доставляются в Minecraft
1. Проверьте, что сервер запущен (`/status`)
2. Проверьте RCON пароль в `.env`: `MINECRAFT_RCON_PASSWORD`
3. Проверьте, что `mcrcon` установлен на сервере
4. Проверьте логи бота: ищите ошибки RCON

### События не приходят в Telegram
1. Убедитесь, что мониторинг включен в настройках
2. Проверьте `NOTIFICATION_GROUP_ID` в `bot.py`
3. Проверьте, что бот имеет права отправки сообщений в группу
4. Проверьте логи бота: ищите ошибки парсинга

### Неправильно распознаются события
1. Проверьте формат логов: `journalctl -u minecraft.service -n 50`
2. Возможно, нужно обновить регулярные выражения в `MinecraftLogParser.PATTERNS`

## 📄 Конфигурация

### Переменные окружения (.env)

```env
# RCON пароль (должен совпадать с server.properties)
MINECRAFT_RCON_PASSWORD=your_rcon_password

# SSH доступ к серверу
MINECRAFT_SERVER_SSH=root@your-server-ip:22
MINECRAFT_SERVER_KEY_FILE=/path/to/ssh/key

# Telegram
TELEGRAM_TOKEN=your_bot_token
NOTIFICATION_GROUP_ID=-1234567890
```

### server.properties (Minecraft)

Убедитесь, что RCON включен:

```properties
enable-rcon=true
rcon.port=25575
rcon.password=your_rcon_password
```
