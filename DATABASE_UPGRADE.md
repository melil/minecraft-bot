# Обновление системы администрирования бота

## Что было сделано

### 1. Создана база данных для управления пользователями

**Файлы:**
- `core/database/__init__.py` - модуль базы данных
- `core/database/models.py` - модели данных (User, UserRole)
- `core/database/database.py` - логика работы с БД

**Модель пользователя:**
```python
class User:
    - telegram_id (уникальный)
    - username (Telegram username)
    - first_name
    - last_name
    - minecraft_nickname (новое поле)
    - telegram_link (новое поле)
    - role (USER/ADMIN/SUPER_ADMIN)
    - created_at
    - updated_at
```

### 2. Система ролей

**Три уровня доступа:**

1. **USER** - обычный пользователь
   - Может видеть статус сервера
   - Может проверять список игроков
   - Может видеть баланс

2. **ADMIN** - администратор
   - Все права USER
   - Может запускать/останавливать/перезагружать сервер
   - Может добавлять/удалять других админов
   - Может управлять настройками
   - Может устанавливать Minecraft ники пользователям

3. **SUPER_ADMIN** - супер-администратор (ID: 78120051)
   - Все права ADMIN
   - Может повышать других пользователей до SUPER_ADMIN
   - Не может быть удален из админов

### 3. Автоматическая регистрация пользователей

**Как работает:**
- При любом взаимодействии с ботом пользователь автоматически регистрируется в БД
- Сохраняются: telegram_id, username, имя, фамилия
- Пользователи из списка `ADMIN_IDS_FOR_AUTO_PROMOTION` автоматически получают роль ADMIN

**Список автоповышения (в bot.py):**
```python
ADMIN_IDS_FOR_AUTO_PROMOTION = [
    138349349,
    140821964,
    451548653,
    78120051,   # SUPER_ADMIN
    851242077,
    505878676,
    860938417,
]
```

### 4. Новые команды

#### Для всех пользователей:
- `/set_minecraft_nick <ник>` - установить свой Minecraft ник

#### Для администраторов:
- `/set_minecraft_nick <id> <ник>` - установить ник другому пользователю

#### Для супер-администраторов:
- `/promote_super_admin <id>` - повысить пользователя до супер-админа

#### Обновленные команды:
- `/list_admins` - теперь показывает:
  - ID пользователя
  - Роль (👑 для супер-админа, 🔑 для админа)
  - Username
  - Minecraft ник (если установлен)

### 5. Миграция данных

**Скрипт миграции:** `migrate_admins.py`
- Создает базу данных
- Добавляет всех администраторов из списка
- Устанавливает ID 78120051 как SUPER_ADMIN
- Остальных как ADMIN

**Запуск:**
```bash
python migrate_admins.py
```

### 6. Изменения в коде

**bot.py:**
- Удалены функции `load_admin_ids()` и `save_admin_ids()`
- Добавлена функция `register_or_update_user()` для автоматической регистрации
- Добавлена функция `is_super_admin()`
- Создан `DatabaseAdminManager` вместо старого `AdminManager`
- Убрана работа с файлом `admins.txt`

**Все команды обновлены:**
- `core/bot/commands/base.py` - добавлена автоматическая регистрация пользователей
- `core/bot/commands/info.py` - регистрация при каждой команде
- `core/bot/commands/server.py` - регистрация при управлении сервером
- `core/bot/commands/admin.py` - новые команды для управления
- `core/bot/commands/settings.py` - регистрация пользователей
- `core/bot/commands/balance.py` - регистрация пользователей

**button_callback:**
- Добавлена автоматическая регистрация при нажатии на кнопки

## Безопасность

- База данных не попадает в git (добавлена в .gitignore)
- Супер-админа нельзя удалить из списка админов
- Только супер-админы могут создавать других супер-админов
- Все пользователи отслеживаются в БД

## Обратная совместимость

- Старый файл `admins.txt` сохранен, но больше не используется
- Все ID из старого файла автоматически переносятся в БД при миграции
- Функция `is_admin()` работает так же, но теперь проверяет БД
