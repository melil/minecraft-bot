# 🚀 Быстрый старт: Общение Telegram ↔ Minecraft

## 📤 Отправка сообщений из Telegram в Minecraft

### Команды для отправки (для админов):
```
/say Привет всем!        # Обычная команда
/mc Привет всем!         # Короткая версия
```

### Примеры полезных RCON команд (только для супер-админов):
```
/rcon time set day       # Установить день
/rcon weather clear      # Очистить погоду
/rcon save-all          # Сохранить мир
/rcon list              # Список игроков
```

---

## 📥 Получение событий из Minecraft в Telegram

### Как включить:

1. Отправьте `/start` боту
2. Нажмите "⚙️ Настройки"
3. Нажмите "📜 Мониторинг событий MC: 🔴 ВЫКЛ"
4. Статус изменится на "🟢 ВКЛ"

### Что будет приходить в группу:

- ➕ **Вход:** `Steve присоединился к игре`
- ➖ **Выход:** `Alex покинул игру`
- 💬 **Чат:** `Steve: Привет всем!`
- 💀 **Смерть:** `Steve был убит зомби`
- 🏆 **Достижение:** `Alex получил достижение: Stone Age`

## ⚙️ Настройка (один раз)

### 1. Проверьте `.env` файл:
```env
MINECRAFT_RCON_PASSWORD=SuperPassword228  # Ваш RCON пароль
```

### 2. Убедитесь, что в `server.properties`:
```properties
enable-rcon=true
rcon.port=25575
rcon.password=SuperPassword228  # Тот же пароль
```

### 3. Проверьте, что `mcrcon` установлен на сервере:
```bash
ssh root@your-server
which mcrcon  # Должен показать путь
```

Если не установлен:
```bash
# Ubuntu/Debian
apt install mcrcon

# Или скомпилировать:
git clone https://github.com/Tiiffi/mcrcon.git
cd mcrcon
make
cp mcrcon /usr/local/bin/
```

## 🔧 Если что-то не работает

### Сообщения не доставляются в Minecraft:
```bash
# На сервере проверьте RCON вручную:
mcrcon -H 127.0.0.1 -P 25575 -p SuperPassword228 "say Hello"
```

Если выдает ошибку - проверьте `server.properties` и перезапустите Minecraft.

### События не приходят в Telegram:
```bash
# Проверьте логи Minecraft:
journalctl -u minecraft.service -n 50 --no-pager

# Должны быть строки типа:
# [Server thread/INFO]: Player joined the game
# [Server thread/INFO]: <Player> hello
```

Если логов нет - проблема с Minecraft сервисом, не с ботом.

## 💡 Полезные сценарии

### Предупреждение перед рестартом:
```
/say ⚠️ Сервер будет перезагружен через 5 минут!
(через 4 минуты)
/say ⚠️ Рестарт через 1 минуту! Выходите из игры!
(через 1 минуту)
/rcon save-all
(нажать кнопку Restart)
```

Включите мониторинг и смотрите в группе:
- Кто и когда заходит
- О чем общаются игроки
- Кто получил достижения
