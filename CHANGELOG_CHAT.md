# 📝 Changelog: Функционал общения Telegram ↔ Minecraft

## 🎉 Что добавлено

### ✨ Новые возможности

#### 1. Отправка сообщений из Telegram в Minecraft
- ✅ Команда `/say <текст>` - отправить сообщение в игровой чат
- ✅ Команда `/mc <текст>` - короткий алиас для `/say`
- ✅ Команда `/rcon <команда>` - выполнить любую RCON команду
- ✅ Отображение имени отправителя в Minecraft: `[Telegram: username] сообщение`
- ✅ Проверка прав доступа (только админы)
- ✅ Проверка статуса сервера перед отправкой

#### 2. Мониторинг событий из Minecraft в Telegram
- ✅ Вход игроков (➕ Player joined the game)
- ✅ Выход игроков (➖ Player left the game)
- ✅ Сообщения в чате (💬 Player: message)
- ✅ Смерти (💀 death message)
- ✅ Достижения (🏆 Player has made advancement)
- ✅ Реальное время (проверка логов каждые 2 секунды)
- ✅ Отправка в Telegram группу

#### 3. Настройки мониторинга
- ✅ Включение/выключение через inline кнопку в настройках
- ✅ Автоматический запуск/остановка при старте/остановке сервера
- ✅ Настройка типов отображаемых событий в конфиге
- ✅ По умолчанию ВЫКЛЮЧЕНО (не спамит)

## 📁 Новые файлы

### Основные модули
1. **`core/minecraft/rcon.py`** - RCON клиент для отправки команд
   - `execute_rcon_command()` - выполнение команд
   - `say()` - отправка сообщений в чат
   - `tellraw()` - форматированные сообщения
   - `list_players()` - список игроков

2. **`core/minecraft/log_monitor.py`** - Мониторинг логов Minecraft
   - `MinecraftLogParser` - парсер событий из логов
   - `MinecraftLogMonitor` - система мониторинга в реальном времени
   - События: `PlayerJoinEvent`, `PlayerLeaveEvent`, `ChatMessageEvent`, `PlayerDeathEvent`, `PlayerAchievementEvent`

3. **`core/bot/commands/chat.py`** - Команды общения с Minecraft
   - Обработчик `/say`
   - Обработчик `/mc`
   - Обработчик `/rcon`

### Документация
4. **`MINECRAFT_CHAT.md`** - Полная документация по функционалу
5. **`QUICKSTART_CHAT.md`** - Быстрый старт
6. **`CHANGELOG_CHAT.md`** - Этот файл
7. **`README.md`** - Обновлён с новым функционалом

### Тесты
8. **`test_rcon.py`** - Скрипт для тестирования RCON

## ⚙️ Настройки конфигурации

### Переменные окружения (.env)
```env
# Новая переменная (опционально, есть дефолт)
MINECRAFT_RCON_PASSWORD=SuperPassword228
```

### server.properties (Minecraft)
```properties
# Должно быть включено
enable-rcon=true
rcon.port=25575
rcon.password=SuperPassword228
```

### bot.py конфигурация
```python
# Мониторинг логов (по умолчанию выключен)
log_monitoring_enabled = False

# Типы отображаемых событий
MINECRAFT_EVENTS_CONFIG = {
    'join': True,      # Вход игроков
    'leave': True,     # Выход игроков
    'chat': True,      # Сообщения в чате
    'death': True,     # Смерти
    'achievement': True  # Достижения
}
```

## 🧪 Как протестировать

### Вариант 1: Автоматический тест
```bash
python test_rcon.py
```

### Вариант 2: Ручное тестирование

1. **Запустите бота:**
   ```bash
   python bot.py
   ```

2. **Тест отправки сообщений:**
   ```
   /start
   (Запустите сервер если не запущен)
   /say Привет из Telegram!
   ```
   Проверьте, что сообщение появилось в Minecraft

3. **Тест мониторинга событий:**
   ```
   /start → ⚙️ Настройки → 📜 Мониторинг событий MC (включить)
   ```
   Зайдите на сервер, напишите что-то в чат
   Проверьте, что события приходят в Telegram группу

4. **Тест RCON команд:**
   ```
   /rcon time set day
   /rcon weather clear
   /rcon list
   ```

## 🐛 Known Issues / Ограничения

1. **Парсинг логов:**
   - Зависит от формата логов journalctl
   - Может не работать с кастомными логгерами
   - Задержка ~2 секунды

2. **RCON:**
   - Требует `mcrcon` на сервере
   - Порт 25575 должен быть доступен локально
   - Не работает если сервер падает/крашится

3. **Производительность:**
   - Мониторинг логов каждые 2 секунды (можно настроить)
   - Может пропустить события если сервер очень активен
