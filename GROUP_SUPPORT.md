# Обновление: Поддержка команд в группе

## Что изменилось

### 1. Добавлена таблица Groups в базу данных

**Новая модель Group:**
- `telegram_id` - ID группы
- `title` - название группы
- `username` - username группы (если есть)
- `type` - тип (group/supergroup/channel)
- `is_active` - активна ли группа
- `commands_enabled` - включены ли команды в группе
- `created_at` / `updated_at` - временные метки

### 2. Команды теперь работают в группе

Группа с ID `-5142213077` захардкожена в коде.

**Команды, доступные в группе:**
- `/start` - показывает кнопки управления
- `/status` - статус сервера с кнопками
- `/players` - список игроков
- `/balance` - информация о балансе
- `/start_server` - запуск сервера (все в группе могут использовать)
- `/stop_server` - остановка сервера
- `/restart_server` - перезагрузка сервера
- `/settings` - настройки автовыключения

**Кнопки работают в группе:**
- Все участники группы видят админские кнопки
- Кнопки работают для всех в разрешенной группе

### 3. Автоматическая регистрация групп

При любом взаимодействии в группе:
- Группа автоматически добавляется в БД
- Сохраняется название, username, тип
- Обновляется при изменении данных группы

### 4. Логика доступа

**В группе (ID: -5142213077):**
- Все команды работают для всех участников
- Показываются админские кнопки
- Команды в других группах игнорируются

**В личных сообщениях:**
- Админские команды только для администраторов
- Обычные команды (/status, /players, /balance) для всех

## Технические детали

### Изменения в коде:

1. **core/database/models.py**
   - Добавлена модель `Group`
   - Изменен тип `telegram_id` с `Integer` на `BigInteger` (для поддержки отрицательных ID групп)

2. **core/database/database.py**
   - Добавлены методы для работы с группами:
     - `get_or_create_group()`
     - `get_group_by_telegram_id()`
     - `is_group_commands_enabled()`
     - `set_group_commands_enabled()`
     - `get_all_groups()`

3. **core/bot/commands/base.py**
   - Добавлена константа `NOTIFICATION_GROUP_ID = -5142213077`
   - Добавлен метод `_register_group_if_needed()`
   - Добавлен метод `_is_allowed_group()`

4. **Все команды обновлены:**
   - Регистрируют группу при вызове
   - Проверяют ID группы перед выполнением
   - Работают как в группе, так и в ЛС

5. **bot.py**
   - Добавлена функция `register_or_update_group()`
   - Регистрация группы в `button_callback`
   - Передача `group_registrar` во все команды

## Миграция

База данных автоматически создаст новую таблицу `groups` при первом запуске.

Если у вас уже есть база данных, просто перезапустите бота - SQLAlchemy автоматически создаст недостающие таблицы.

## Использование

### В группе -5142213077:

1. Добавьте бота в группу
2. Используйте команды как обычно
3. Кнопки будут работать для всех участников

### Команды в группе:

```
/start - показать кнопки управления
/status - статус сервера
/players - список игроков
/balance - баланс VPS
/start_server - запустить сервер
/stop_server - остановить сервер
/restart_server - перезагрузить сервер
/settings - настройки
```

### В других группах:

Бот будет молча игнорировать команды (не будет отвечать).

## Безопасность

- ID группы захардкожен в коде (`-5142213077`)
- Команды в других группах не работают
- Все действия логируются в базу данных
- Пользователи регистрируются при каждом взаимодействии
