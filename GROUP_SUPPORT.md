# Обновление: Поддержка команд в supergroup с топиками

## Что изменилось

### 1. Добавлена таблица Groups в базу данных

**Новая модель Group:**
- `telegram_id` - ID supergroup
- `title` - название supergroup
- `username` - username supergroup (если есть)
- `type` - тип (group/supergroup/channel)
- `is_active` - активна ли supergroup
- `commands_enabled` - включены ли команды в supergroup
- `created_at` / `updated_at` - временные метки

### 2. Команды теперь работают в supergroup

Supergroup с ID `-1003506839886` захардкожена в коде. Бот поддерживает supergroup с топиками.

**Команды, доступные в группе:**
- `/start` - показывает кнопки управления
- `/status` - статус сервера с кнопками
- `/players` - список игроков
- `/balance` - информация о балансе
- `/start_server` - запуск сервера (все в группе могут использовать)
- `/stop_server` - остановка сервера
- `/restart_server` - перезагрузка сервера
- `/settings` - настройки автовыключения

**Кнопки работают в группе:**
- Все участники группы видят админские кнопки
- Кнопки работают для всех в разрешенной группе

### 3. Автоматическая регистрация групп

При любом взаимодействии в группе:
- Группа автоматически добавляется в БД
- Сохраняется название, username, тип
- Обновляется при изменении данных группы

### 4. Логика доступа

**В supergroup (ID: -1003506839886):**
- Все команды работают для всех участников
- Показываются админские кнопки
- Команды в других supergroup/группах игнорируются
- Команды и кнопки работают в общем чате (без топика)
- Автоматические уведомления отправляются в соответствующие топики

**В личных сообщениях:**
- Админские команды только для администраторов
- Обычные команды (/status, /players, /balance) для всех

## Технические детали

### Изменения в коде:

1. **core/database/models.py**
   - Добавлена модель `Group`
   - Изменен тип `telegram_id` с `Integer` на `BigInteger` (для поддержки отрицательных ID групп)

2. **core/database/database.py**
   - Добавлены методы для работы с группами:
     - `get_or_create_group()`
     - `get_group_by_telegram_id()`
     - `is_group_commands_enabled()`
     - `set_group_commands_enabled()`
     - `get_all_groups()`

3. **core/bot/commands/base.py**
   - Добавлена константа `NOTIFICATION_GROUP_ID = -1003506839886` (supergroup)
   - Добавлен метод `_register_group_if_needed()`
   - Добавлен метод `_is_allowed_group()`

4. **core/config.py**
   - Добавлена конфигурация `NOTIFICATION_TOPICS` для маппинга событий на топики

5. **Все команды обновлены:**
   - Регистрируют supergroup при вызове
   - Проверяют ID supergroup перед выполнением
   - Работают как в supergroup, так и в ЛС

6. **bot.py**
   - Добавлена функция `register_or_update_group()`
   - Регистрация supergroup в `button_callback`
   - Передача `group_registrar` во все команды
   - Функция `notify_group()` поддерживает отправку в топики через `message_thread_id`
   - `minecraft_event_handler()` отправляет события в соответствующие топики

7. **core/minecraft/log_monitor.py**
   - Функция `send_event_to_telegram()` поддерживает отправку в топики через `message_thread_id`

## Миграция

База данных автоматически создаст новую таблицу `groups` при первом запуске.

Если у вас уже есть база данных, просто перезапустите бота - SQLAlchemy автоматически создаст недостающие таблицы.

## Использование

### В supergroup -1003506839886:

1. Добавьте бота в supergroup
2. Используйте команды как обычно в общем чате
3. Кнопки будут работать для всех участников в общем чате
4. Автоматические уведомления отправляются в соответствующие топики:
   - **Топик 2 (logs)**: вход/выход игроков, сообщения в чате MC, смерти, достижения
   - **Топик 30 (chat)**: сообщения с префиксом `tg:` из Minecraft
   - **Топик 39 (status)**: уведомления о статусе сервера (запуск/остановка/перезагрузка)

### Команды в группе:

```
/start - показать кнопки управления
/status - статус сервера
/players - список игроков
/balance - баланс VPS
/start_server - запустить сервер
/stop_server - остановить сервер
/restart_server - перезагрузить сервер
/settings - настройки
```

### В других supergroup/группах:

Бот будет молча игнорировать команды (не будет отвечать).

## Топики

Бот автоматически отправляет уведомления в соответствующие топики:
- **Топик 2 (logs)**: события из логов Minecraft (join, leave, chat, death, achievement)
- **Топик 30 (chat)**: сообщения с префиксом `tg:` из Minecraft
- **Топик 39 (status)**: уведомления о статусе сервера

Команды и кнопки работают в общем чате (без топика) - это стандартное поведение Telegram.

## Безопасность

- ID supergroup захардкожен в коде (`-1003506839886`)
- Команды в других supergroup/группах не работают
- Все действия логируются в базу данных
- Пользователи регистрируются при каждом взаимодействии
