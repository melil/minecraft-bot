# Миграция на базу данных

## Что изменилось

Бот теперь использует SQLite базу данных для хранения пользователей вместо текстового файла `admins.txt`.

### Новые возможности:

1. **База данных пользователей** - все пользователи автоматически добавляются в БД при первом взаимодействии с ботом
2. **Роли пользователей:**
   - `USER` - обычный пользователь
   - `ADMIN` - администратор (может управлять сервером)
   - `SUPER_ADMIN` - супер-администратор (может управлять другими администраторами)

3. **Дополнительные поля:**
   - Telegram username
   - Имя и фамилия
   - Minecraft никнейм
   - Ссылка на Telegram профиль

4. **Автоматическое повышение** - пользователи из списка `ADMIN_IDS_FOR_AUTO_PROMOTION` автоматически получают права администратора при первом взаимодействии

### Новые команды:

- `/set_minecraft_nick <ник>` - установить свой Minecraft ник
- `/set_minecraft_nick <id> <ник>` - установить ник другому пользователю (только для админов)
- `/promote_super_admin <id>` - повысить пользователя до супер-админа (только для супер-админов)

## Миграция

### Шаг 1: Установите зависимости

```bash
pip install -r requirements.txt
```

### Шаг 2: Запустите скрипт миграции

```bash
python migrate_admins.py
```

Этот скрипт:
- Создаст таблицы в базе данных (bot.db)
- Добавит всех администраторов из списка
- Установит пользователя 78120051 как SUPER_ADMIN
- Остальных как ADMIN

### Шаг 3: Запустите бота

```bash
python bot.py
```

## Важно!

- Файл `bot.db` автоматически создастся при первом запуске
- База данных добавлена в `.gitignore`
- Старый файл `admins.txt` больше не используется, но сохранен для истории
